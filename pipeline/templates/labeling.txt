Label one slide for the eightytwenty design library. Work only from these files:
  - {slide}.png   the rendered slide (look at it)
  - {slide}.json  extracted regions: index "i", type, normalised box, colour/type roles, text counts

Write ONE JSON object to labels/{slide}.json (in this folder). It must validate against
pipeline/schema/labels.v1.json. Fields:

  archetype       one of: {archetypes}
  purpose         what job the slide does in the argument, abstract, 10-200 characters
  argument_shape  one of: {argument_shapes}
  insight_device  one of: {insight_devices}
  data_type       one of: {data_types}
  industry        coarse industry, one of: {industries}
  why_it_works    why the design works, 20-400 characters
  regions         an object mapping EVERY region index from {slide}.json (as a string) to a role, one of:
                  {roles}
  text_patterns   for each text region worth imitating: {{"region": <index>, "pattern": "<shape of the text>",
                  "words": <word count>}}, e.g. {{"region": 3, "pattern": "claim + mechanism + number", "words": 14}}

Hard rules for every free-text field (purpose, why_it_works, pattern). A leak check rejects the record otherwise:
  - Describe the design, never the content. No client, competition, team, school, year, person, company,
    brand, product or place names, and no hint that identifies them.
  - No digits at all (write "one big number", not "3x").
  - Never copy three or more consecutive words from the slide's text.
  - No other fields than the ones above.
