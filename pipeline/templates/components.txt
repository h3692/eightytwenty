Look at the picture zoomed out: what are the 3-8 major blocks that give the slide its structure? Pick one component
for each. Ignore everything smaller: single icons, decoration, connectors, footnotes, page numbers, sources.
Every slide gets a title + subtitle header (top-left) automatically, except cover, section_divider and closing.

Placement: "box" is [x, y, w, h], floats 0-1 of the CONTENT AREA (below the header, above the bottom tracker),
not of the whole slide; x + w <= 1, y + h <= 1. It is snapped to a 12 x 8 grid (12 columns, 8 rows), so think
in grid cells: a full-width bar one row high at the bottom is [0, 0.875, 1, 0.125]. Blocks side by side or stacked
should not overlap. The listed regions are an optional alignment hint: use them only to place edges more exactly;
the picture decides.

Components (kind and its only fields; integers are counts you read off the picture):
  tracker          n 2-8 pills along the bottom, active 1-n = the highlighted one (a section/agenda tracker
                   strip at the top or bottom of the slide). No box.
  logo             a logo top-right. No box.
  text             box, lines 1-8, bullets true|false: a block of running text or a bullet list (drawn as at
                   most 4 placeholder lines)
  kpi_row          box, n 1-6, direction h|v, tile round|square: big-number tiles (value + caption) in a row,
                   or stacked down the slide (v); round = circular tiles
  card_stack       box, n 2-8, header_strip true|false, icon true|false: cards stacked top to bottom (a vertical
                   list of boxes; a row of boxes is card_row)
  card_row         box, n 1-6, header_strip true|false, icon true|false: a row of boxes/cards with content
  label_rows       box, rows 1-10, cols 1-4: rows each led by a dark label cell (a row-labelled grid or matrix)
  table            box, rows 1-12, cols 1-12, header_row true|false, marks none|harvey|check (harvey = rating
                   balls, check = tick/cross grid), highlight_col 1-cols (one emphasised column, heat-map style)
  bar_list         box, n 2-12, groups 1-4: a list of labelled horizontal bars (budget or ranking list); groups
                   = header bars that the items sit under
  link_list        box, n 2-12, cols 1-3, numbered true|false: an appendix or contents list of n entries down
                   1-3 columns, each numbered (true) or bulleted (false)
  chart_area       box, chart_type one of: {chart_types} (other = map, sankey, anything else)
  image_area       box, variant one of: {variants} (device = product mockup or screenshot)
  device_row       box, n 1-6, device phone|laptop: a row of phone or laptop screens (app screenshots)
  gauge_row        box, n 1-6, direction h|v: donut gauges (a percentage each), in a row or stacked
  steps            box, n 2-8, direction h|v: a numbered process or sequence of steps
  timeline         box, workstreams 1-10, periods 2-24, milestones true|false, rounded true|false, groups 2-6:
                   a Gantt chart; rounded = pill bars, groups = year pills above the period headers
  swimlane         box, lanes 2-6, stages 2-8, curve true|false: lanes (rows) by stages (columns), e.g. a
                   service blueprint; curve = a sentiment/emotion line above the lanes
  journey          box, n 3-8, curve true|false, persona true|false: milestones along one horizontal axis with
                   labels alternating above and below; curve = a wavy path, persona = a profile slot at the left
  stage_strip      box, n 2-6, active 1-n: a row of chevrons with one highlighted (a process-stage strip, often
                   across the top; may sit alongside the tracker)
  roadmap          box, phases 2-6: phases left to right with content under each
  matrix           box, dots 0-8: a 2x2 matrix with plotted items
  flow_diagram     box, n 3-10, arrangement row|grid, icon true|false: boxes joined by arrows (a process or
                   system flow); grid wraps the boxes onto rows
  network          box, n 3-12: nodes joined by lines (an ecosystem, ERD or relationship web)
  map_callouts     box, n 1-8: a map with numbered markers and their labels beside it
  tree             box, levels 2-4, branching 2-4: an issue/driver tree (at most 16 leaves)
  funnel           box, stages 2-6
  nested_circles   box, n 2-4, arrangement nested|concentric: circles inside each other (TAM/SAM/SOM), each with
                   a header and a share; nested = resting on one bottom point, concentric = sharing a centre
  hub              box, n 3-8, connectors true|false, cycle true|false: a centre node with n satellites around
                   it (hub-and-spoke); connectors = lines from the centre to each satellite, cycle = arrows
                   running round the satellites
  before_after     box, rows 1-4: a before -> after contrast
  takeaway         box: the one-line conclusion bar
  quote            box: a quotation
  hero_number      box: one huge number the slide is built around
  section_divider  number 1-9: a section opener slide. No box.
  cover            the deck's title slide. No box.
  closing          a thank-you / questions slide. No box.
  impact_overlay   position top|middle|bottom: use for a slide that repeats the previous slide shaded with a ribbon
                   carrying the so-what: copy the parent slide's components, then add impact_overlay last (it counts
                   toward the 8; position = where the ribbon crosses the content area). No box.

A blank or spacer slide (nothing on it, or only a stray placeholder text box) is {{"version": 3, "blank": true,
"components": []}}: blank slides are never published.

Choose the nearest kind; when several fit, take the simpler one (a grid of text cells with dark row labels is
label_rows, a grid with a header row is a table, a row of boxes is card_row).

Hard rules:
  - No words from the slide and no fields other than the ones above: the mockup only ever shows fixed placeholder

  - Write only the JSON file(s) this worksheet asks for, nothing else.
